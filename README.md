# ML_Permeability4PorousMaterials

Predict permeability tensors of porous materials from microstructure features using neural networks, and inversely design microstructures to achieve a target permeability.

**Pipeline:** 3D porous geometry → LBM fluid simulation → dataset → forward neural network → inverse neural network

## Installation

### Neural Network Module

Requires **Python 3.10+**. A CUDA-capable GPU is optional but recommended.

```bash
cd neural-net
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### LBM Simulation Module (HPC only)

Requires **Python 3.11+**, a CUDA-capable GPU, and an HPC environment with SLURM.

```bash
cd lbm_simulation
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> **Note:** The SLURM job script (`job.sh`) loads specific modules (GCC 12.3.0, Python 3.11.3, CUDA 12.6.0). Adapt these to your cluster.

## Quick Start

Train the forward model, then the inverse model:

```bash
cd neural-net

# Train forward model (features → permeability)
python train_model.py

# Train inverse model (permeability → features)
python train_inverse_model.py -f forward_model_output/best_model.pt
```

With hyperparameter tuning (recommended):

```bash
python train_model.py --tune
python train_inverse_model.py -f forward_model_output/best_model.pt --tune
```

## Dataset

The file `neural-net/256-final.csv` contains **12,911 samples** with 46 columns, generated by running LBM simulations on synthetic porous geometries.

- **Features (11):** `a20, a11, a02, a10, a01, a00, m` (Curvatubes generation parameters), `porosity`, `tortuosity_geometric_x/y/z`
- **Targets (3):** `K_xx, K_yy, K_zz` (diagonal Darcy permeability tensor components)
- **Split:** 70% train / 20% validation / 10% test (seed 42)
- **Preprocessing:** Targets are log10-transformed (floor `1e-30`) then MinMax-scaled to [0, 1]
